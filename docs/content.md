# Content

Positioning: AI consulting and implementation. The site explains four connected services: consulting, workflow automation, engineering, and team enablement. Scope, timing, deliverables, and cost are agreed per engagement. The primary conversion path is a direct inquiry, with booking and email alternatives.

All route content is maintained in `scripts/build.py`. Edit source content there; do not edit generated `dist` HTML. Existing education/events URLs remain useful but make no unsupported public-date or program-availability claims.

Public copy includes no named client proof, private project facts, performance metrics, guaranteed results, prices, or fixed delivery promises. The founder is Shafan Khan. Private evidence stays outside this repository and publish tree.

Every route has a unique title, description, canonical URL, one H1, and shared navigation. Sitemap, robots, and llms files are generated from the same route map.
